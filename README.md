# Portfólio — Eduardo Rodrigues

Portfólio pessoal desenvolvido para apresentar minha trajetória, projetos e conhecimentos em tecnologia de uma forma simples para recrutadores, gestores e pessoas técnicas.

O site destaca projetos pelo problema que resolvem e pelo que já entregam, deixando os detalhes técnicos como apoio.

## Projetos em destaque

- **OrganizaMeuDia** — produto próprio em desenvolvimento para reunir agenda, tarefas, finanças e listas em um único ambiente.
- **Portaria Inteligente — LPR** — protótipo de automação e visão computacional para identificar placas, consultar autorizações e registrar acessos.

## Tecnologias

HTML, CSS e JavaScript no portfólio, além de Python, SQL, SQLite, OpenCV, OCR, Git, GitHub, pytest e outras ferramentas aplicadas nos projetos.
